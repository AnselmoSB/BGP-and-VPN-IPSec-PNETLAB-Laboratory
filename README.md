## Construindo uma topologia de rede com implementação de eBGP com IPSec

Um cenário baseado em uma necessidade real onde, a implementação de um link LAN-to-LAN entre empresa e cliente estava muito demorada pois nenhuma operadora atendia a região do cliente com esta tecnologia. Foi solicitado então a validação da tecnologia de IPSEC para suprir a necessidade desse cliente.
